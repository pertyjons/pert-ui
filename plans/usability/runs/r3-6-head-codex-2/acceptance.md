replace_text, settle, find, address_children, semantics}`;

inspection snapshot (component `visible`, properties such as Dialog `open`,
TabList `tab_count`, semantics names and values) and from the files on disk.

Menu items are clicked with the pointer. In 0.3.88 the menu title is not
addressable (path `None`) and menu rows report no item bounds, so
`Driver::click_item` cannot target them. The helper `Ui::menu`
(`verifier_acceptance.rs:245`) therefore does four things:
1. finds the `title/file` child of the bar with `Runtime::children` and
   clicks it with `Driver::click`;
2. moves the pointer in 2 px steps down the open menu (`Runtime::pointer_input`
   Move) until the menu's semantic value reports the wanted row
   highlighted;
3. presses and releases the primary button at that point;
4. asserts that the menu has closed.

## Observations (not grading)

Application:
- The failure notification is an unstyled Label flush with the window's
  bottom-left edge (see `failed-save-notification.png`). It has no
  Notifications role and no emphasis, and it stays until the next
  successful save. Message discoverability is weak but present. Recorded
  separately, as the round rules require.
- Sorting is `Vec::sort` byte order, so capitals sort first:
  `Groceries.txt` before `existing.txt`. The task does not define case
  handling, so this is not graded. Item 1 uses lowercase names.
- The status line is a per-tab Label inside each tab page. Only the active
  page's label is visible, and with no tab open there is no status text.

Library (for triage, not application defects):
- Menu-bar titles are not addressable, and menu rows and tab titles report
  no item bounds. A pointer test of a menu row needs a hover scan, and
  `Driver::click_item` on tabs fails with `ItemWithoutBounds` (the tester's
  FRICTION.md). This matches the menu/tab geometry gap already confirmed in
  the round 3 triage.
- Tester friction: `SplitPane`/`SplitAxis`/`SplitSizing` are not in the
  prelude, `VirtualList::on_activate` is Enter-only, and cross-axis stretch
  needs `Column::align(Align::Stretch)`.
