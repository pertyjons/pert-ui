# Round 3 literal-tab coverage: implementation evidence

Implementation author's evidence for the approved revision-3 design
(`plans/usability/round-3-design-tabs-whitespace.md` and the accepted r2/r3
reviews). The worktree is `/home/per/pert-ui-usability/r3-text-worktree`,
based on HEAD `3bbfb81`. Nothing is committed or staged. The private target
directory is `/home/per/pert-ui-usability/r3-text-implementation-target`.

This is not an independent review. No native, GPU, Windows/macOS or human-input
evidence was produced. CPU rendering and captures are CPU evidence only.

## Files

- `checks/` holds the final run of every check: the command header, exit
  status and full output. `run-checks.out` and `checks/summary.txt` summarize
  it. All 17 checks exited 0.
- `checks-attempt1/` is the first run, kept as a record. It had two failures:
  an unused `Duration` import under default features (Clippy -D warnings),
  and a malformed filter command for check 12. Both were fixed before the
  final run.
- `negative-controls/` holds `run.py`, one log per control and
  `summary.txt`. Each control temporarily mutates the implementation, runs
  `text::tabs` and restores the sources, checking their hashes.
  `old-run-negative-controls/` is the same set run against an earlier code
  shape.
- `fixture/provenance.log` shows the fixture regenerated byte-identically with
  fontTools 4.60.1 and Python 3.14.8, its hashes, the generator diff against
  the prepared original, no developer paths and no build-time generation.
- `cpu-capture/` is an out-of-tree program using the public facade (`cpu`
  feature), with `capture-run.log` and the `captures/*.png` files.
- `implementation-tracked.diff`, `implementation-untracked.diff` and
  `worktree-state.log` record the reviewable change and the file hashes.

## Requirement to evidence

All `text::tabs::tests::*` live in `crates/pert-ui-runtime/src/text/tabs.rs`.
The facade tests are `tab_whitespace::*` in
`crates/pert-ui/tests/editing/tab_whitespace.rs`.

- **Pre-fix reference.** `TextService::hide_tabs = false` (test-only) skips the
  overrides inside the same `build_layout`. The tests compare against it
  through `services()`.
- **Body/Monospace tabs (leading, embedded, repeated, wrapped, multiline).**
  `tabs_keep_the_reference_geometry_and_unicode_analysis_without_their_ink`
  runs every case at three scales and four widths. It checks:
  - lines, line metrics, run ranges and direction, layout width and height,
    all exact;
  - every glyph ID exact, with x/y within 0.01 physical pixels;
  - caret validity and caret geometry at every byte;
  - every movement from every stop;
  - selection rectangles, `word_at_point` and `at_point`;
  - that the drawn glyphs are exactly the reference's non-tab cluster glyphs;
  - no ink in any hidden tab's advance, where the reference has the box;
  - other pixels within 1 coverage level.

  Size and origin are exact unless a tab hangs at a wrapped line end; see the
  risks below.
- **Tab-only text.** `tab_only_text_has_no_coverage_but_its_advance_and_caret_stops`
  checks no parts, `ink == None`, size equal to the shaped advance and to the
  reference, increasing caret stops, and empty phase parts.
- **Combining mark after a tab is not erased.** Cases `"x\t\u{301}y"` and
  `"\t\u{301}"` in the geometry test: the mark's glyph is drawn, and the purity
  re-walk passes.
- **Unicode, bidi, word, selection and wrap equal to the reference.** The same
  test, with LTR- and RTL-first paragraphs, repeated tabs with word movement,
  and tab plus combining mark.
- **Rich color, size, gap and icon alignment.**
  `rich_spans_gaps_and_icons_keep_reference_color_size_and_alignment` checks
  icon alignment targets equal to the reference, including a hidden tab as an
  icon's only text and icons at bidi run boundaries. It also checks per-brush
  coverage outside tabs and unchanged colors.
- **Registered-font mixed atoms**, with real GSUB shaping of the committed
  fixture.
  `a_registered_font_ligating_a_tab_keeps_that_glyph_and_hides_pure_tab_atoms`
  asserts the shaped glyph IDs and `mixed_tabs` for each case:
  - `\tX` and `X\t`: mixed prefix and suffix;
  - `\t\t`: a pure-tab ligature;
  - `\t\t\tX`: the merged override split to `0..2`;
  - a combined text with a pure tab elsewhere.

  It also checks:
  - actual Parley builds: 1, or exactly 2 for the mixed fallback;
  - one shaping per preparation, and a cache hit with 0 builds;
  - drawn glyphs, ink, and the final-layout purity re-walk;
  - that a mixed atom crossing a color span keeps its first character's color
    and identical parts.
- **Phase collision, both cache orders.**
  `a_tab_and_a_missing_character_never_share_phase_coverage`: the pre-fix
  signatures of `A\tB` and `A\u{E000}B` are equal. The fixed ones differ, and
  in both orders and at three phases, repeated twice, the tab has no ink and
  U+E000 does.
- **U+000B, private-use and unassigned characters keep their fallback ink.**
  `other_unsupported_characters_keep_their_fallback_ink`. The CPU capture
  shows the same for a Body label.
- **Cache hit and miss, `fit_whole`, ellipsis and phase paths.**
  `cached_measured_and_ellipsized_tabs_stay_hidden`:
  - the plain cache hit skips resolution and build, and resolved spans keep
    color indices;
  - `fit_whole` takes one shaping and one build;
  - Ellipsis and MiddleEllipsis candidates keep a tab, matching the reference,
    with no tab ink in default or phase-line parts.
- **Worst admitted alternating tabs, plain and with `MAX_SEGMENTS` spans.**
  `the_worst_admitted_alternating_tabs_stay_within_the_style_bound`: no panic,
  16,385 styles against the bound of 33,796, and one timing observation in
  `checks/06` (debug) and `checks/07` (release):

  | Case | Fixed | Pre-fix reference |
  |---|---|---|
  | Plain | 26.9 ms | 24.0 ms |
  | 1024 spans | 37.6 ms | 23.2 ms |

  Release, on this machine, one sample each, not a bound.
- **Public TextArea.**
  `a_text_area_edits_copies_and_inspects_literal_tabs_as_canonical_bytes`
  covers caret stops around the tab, a backward selection, copy, deleting the
  selected tab, undo, Backspace after a tab, paste, select-all copy, the bound
  value's bytes, the `text` property and the semantic value.
  `keyboard_tab_moves_focus_between_text_areas_without_inserting_a_tab` covers
  Tab and Shift+Tab traversal.
  `a_full_text_area_of_tab_separated_columns_paints_and_edits` is a 300-row,
  900-tab TextArea with a typed tab. Its timing observation is in `checks/10`
  (debug) and `checks/11` (release): 15.0 ms for mount and first frame and
  13.5 ms for one edit frame, release, one sample.
- **Multiline paste keeps tabs; single-line paste normalizes them.** These reuse
  existing tests, run in `checks/12`:
  `text_fields::pasted_control_characters_become_line_breaks_or_are_dropped`
  (multiline keeps `\t`; single-line maps it to a space) and
  `text_fields::text_binding_multiline_defaults_enter_and_undo` (a typed tab in
  a TextField becomes a space).
- **CPU ink.** `a_rendered_tab_is_blank_while_its_neighbors_stay_in_place`
  (`--features cpu`) shows the rendered TextArea `A\tB` pixel-identical to
  `A B`, while `A\u{E000}B` differs. The captures in `cpu-capture/captures/`
  show the same: `textarea-tab.png` and `textarea-space.png` have equal
  hashes.

## Negative controls (final source)

From `negative-controls/summary.txt`. Each mutation was detected:

- **N1, no hiding:** 7 tests fail.
- **N2, no mixed-atom fallback:** the fixture test fails.
- **N3, hidden tabs excluded as icon alignment text:** the rich/icon test
  fails.
- **N4, skip glyph 0 instead of hidden runs:** 6 tests fail, including the
  fallback-ink and fixture tests.
- **N5, hidden runs recorded as color 0 in the signature:** 5 tests fail.
  The phase-collision test itself still passes under N5, because the brush
  split already separates the run structure of `A\tB` from `A\u{E000}B`.
  Omitting hidden runs is what the B1 requirement asks for.
- **N6, a retained tab not splitting the merged range:** the split unit test
  and the fixture test fail.
