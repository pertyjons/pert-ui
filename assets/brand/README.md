# pert-ui brand assets

The mark represents a focused UI component between two interface brackets. The
square is the only accent element; the surrounding brackets and wordmark remain
neutral so the identity works beside application-specific color systems.

Files:

- `pert-ui-icon.svg` is the compact mark for light backgrounds.
- `pert-ui-icon-dark.svg` is the compact mark for dark backgrounds.
- `pert-ui-icon-mono.svg` is the single-color compact mark.
- `pert-ui-logo.svg` is the horizontal mark for light backgrounds.
- `pert-ui-logo-dark.svg` is the horizontal mark for dark backgrounds.
- `pert-ui-logo-mono.svg` is the single-color horizontal mark.

The icon uses a 32-unit grid and remains crisp at 16, 24 and 32 pixels. Every
horizontal lockup embeds that exact icon geometry at the same scale. Keep at
least four units of clear space around the artwork. Use the horizontal logo at
32 pixels high or larger. Do not add an enclosing tile, shadow or gradient to
the master artwork.

The wordmark uses Noto Sans Medium with slightly tightened spacing and is stored
as paths, so the SVG files do not depend on fonts installed on the viewer's
system. The brand assets are covered by the repository's dual MIT/Apache-2.0
license.
